Surface + Measurement

2D mask → Mesh → Area

Use the target 2D mask to select the valid region, then apply Delaunay triangulation to its corresponding 3D points to create a mesh and calculate surface area.

2D MASKDELAUNAY TRIANGULATIONAREA

Output: Clean 3D Mesh & Surface Area

The final user-facing output: a filtered 3D surface model and a surface-area measurement accumulated from its triangle mesh.

Terminology: disparity is the horizontal shift between corresponding pixels in the left and right images. Together with camera calibration parameters, it can be back-projected into a 3D point cloud.
