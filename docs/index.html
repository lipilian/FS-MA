Coarse Engine

Export Coarse Model · ONNX

Run conda run -n fs python python/make_coarse_onnx.py to generate onnx/coarse_engine_1024x1248_iters32.onnx.

Input: left, right · RGB float32[1, 3, 1024, 1248] · range 0–255

Output: disp · float32[1, 1, 1024, 1248]

❗ Important xFormers is disabled during export. The ONNX graph uses standard PyTorch attention/FFN operators, so TensorRT can automatically select and fuse implementations suited to the GPU.

Build Engine · Baseline Test

Build a static TensorRT engine without the aggressive --fp16 tactic flag.

Build: trtexec --onnx=onnx/coarse_engine_1024x1248_iters32.onnx --saveEngine=onnx/coarse_engine_1024x1248_autocast_l3.engine --builderOptimizationLevel=3 --profilingVerbosity=detailed --skipInference

Precision: retain only the FP16 casts already present from PyTorch autocast; do not add TensorRT --fp16 tactics.

❗ Resolution matters The 512 × 608 ONNX exported by make_onnx_liu.py builds successfully. At the target 1024 × 1248 resolution, both exporters reproduce a Myelin failure: No valid tactics to print (all tactics failed), followed by MyelinCheckException: Must have costs and Could not find any implementation for ForeignNode[ONNXTRT_ShapeShuffle ... /Unsqueeze_724]. TensorRT creates only a 0 MiB empty engine. TensorRT chooses tactics for the fixed tensor shapes at build time: increasing resolution changes intermediate tensor sizes, memory demand, and fusion choices, so a tactic valid at 512 × 608 may be unavailable at 1024 × 1248.
❗ Profile first Use --profilingVerbosity=detailed for layer inspection. After profiling, rebuild a clean benchmark engine without detailed profiling verbosity to avoid its enqueue overhead.
